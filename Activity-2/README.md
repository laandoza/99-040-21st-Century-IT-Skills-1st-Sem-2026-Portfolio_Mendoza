Activity Title: Personal Branding

An activity in which we created our own personal branding for a hypothetical business.

What have I learned?:

With this activity I was able to learn about the elements or what makes up a personal branding. My biggest difficulty here was honestly just coming up with a name and designing the logo according to that name. I also spent a lot of time trying to figure out which fonts to use for the typography. If ever I have my own business, what I learned here will help me create a branding for that.
