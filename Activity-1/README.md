Activity Title: Presentation Design Principles
An activity in which we had to create a poster for a free coffee event using specific design principles.

What have I learned?:
With this activity I was able to learn about different design principles used to help make my creations stand out and attract an audience. I think the biggest challenge I faced here was figuring out how to make all the elements of the poster come together to look nice. I think this was really helpful in teaching me the basics of graphic design, so that in the future I can use what I learned for more creative projects.
