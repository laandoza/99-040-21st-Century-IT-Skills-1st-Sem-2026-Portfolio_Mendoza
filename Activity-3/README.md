Activity Title: Social Media Infographics & Project Documentation

An activity in which we had to make an infographic focused on a real world problem and a short documentation about how that problem can be solved with technology.

My biggest problem here was again coming up with an idea, in this case what real world problem I would focus on. I think this idea helped me practice my graphic design, if in any case I have to or want to design more graphics in the future.
