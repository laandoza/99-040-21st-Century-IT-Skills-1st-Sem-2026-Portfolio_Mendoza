Activity Title: Making A Website 

An activity in which we had to create a website for a business or portfolio using an AI tool. 

What have I learned?:

With this activity I was able to learn about different AI tools that specialize in creating websites. The biggest challenge for me here was coming up with what I wanted to put on the website. If ever I need a quick website for something I know I can use AI for it, but I'd honestly rather just make one myself using a non-AI website tool.
